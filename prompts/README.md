# Prompts

Guardar aqui las plantillas de prompt versionadas. Cada prompt debe producir JSON valido, incluir definiciones operacionales, ejemplos cortos y reglas para responder `unclear` cuando el texto no alcance.

Prompt usado actualmente:

- [llm_document_annotation_v1.md](llm_document_annotation_v1.md): prompt unico usado en el piloto `pilot_100_deepseek_full` para relevancia, sentimiento, emociones, narrativa, framing, actores y claims.

Prompts previstos para separar el flujo en versiones futuras:

- `relevance_biodiversity.md`
- `sentiment_emotion.md`
- `narrative_framing.md`
- `actor_roles.md`
- `claim_typology.md`
